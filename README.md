This repository implements a deep learning Convolutional Neural Network (CNN) architecture to classify microscopic blood smear images as either parasitized or uninfected with malaria.

---

## 📊 Project Overview
* **Objective:** Build an accurate medical image classification model to assist in automated malaria parasite detection.
* **Key Steps:**
  * Image preprocessing, normalization, and resizing pipeline for cell images.
  * Convolutional Neural Network (CNN) architecture design featuring convolutional layers, max pooling, dropout, and dense classification layers.
  * Model training, validation, and performance evaluation (Precision, Recall, and F1-Score).
  * Interactive web dashboard deployment via **Streamlit** for real-time cell prediction.
